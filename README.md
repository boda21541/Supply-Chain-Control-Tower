# Supply Chain Control Tower

## Overview
## Dashboard Preview
![Dashboard](images/dashboard_screenshot.png)

Built a simulated Supply Chain Control Tower for a medical device manufacturing environment using SQL and Power BI.

This project helps operations teams proactively monitor:

- Inventory shortages
- Supplier delays
- Safety stock violations
- Purchase order risk
- Critical component availability

---

## Business Problem

Manual tracking of inventory and suppliers often causes:

- Production downtime
- Delayed shipments
- Emergency purchasing
- Poor planning visibility

---

## Solution

Created a centralized SQL-based control tower integrating supplier, inventory, and order data with executive dashboards.
